## 👨‍💻 About Me

I'm a fullstack developer at **Abilium GmbH** in Switzerland, working mainly on private Odoo/ERP projects. Most of my day-to-day code lives in private organisation repositories, so my public contribution graph is much quieter than my actual work.

When I am in public repos, I'm usually tinkering with terminal tooling: my [nvim](https://github.com/lonkous/nvim), [tmux](https://github.com/lonkous/tmux), [kitty](https://github.com/lonkous/kitty) and [dotfiles](https://github.com/lonkous/dotfiles) configurations.

### What I'm into

- Building and refining Odoo/ERP solutions with Python, XML and JavaScript.
- Terminal-first workflows: Neovim, tmux, kitty and a constantly-evolving dotfiles setup.
- Occasional public side projects such as [MarkDownEditor](https://github.com/lonkous/MarkDownEditor) and [Slideshow](https://github.com/lonkous/Slideshow).
